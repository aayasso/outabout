# App Store Screenshots

Run:         `bash tool/screenshots.sh`
Add a shot:  edit `integration_test/screenshot_test.dart`
Change data: edit `integration_test/demo_data.dart`
Requires:    Xcode, iPhone 17 Pro Max simulator runtime
Output:      `marketing/screenshots/raw/iphone_17_pro_max/`

Shot 08 (onboarding) is optional. Comment it out of the SHOTS
array in `tool/screenshots.sh` if not needed.
